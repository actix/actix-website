# Bienvenido a Actix Web {#welcome-to-actix}

Actix Web permite desarrollar servicios web en Rust de forma rápida y segura. Esta guía te ayudará a empezar.

La documentación de este sitio se centra en el framework Actix Web. Para obtener información sobre el framework de actores Actix, consulta el [capítulo de Actix][actix-chapter] o la [documentación de su API][actix-docs]. Para empezar con Actix Web, sigue la [guía de primeros pasos][getting-started]. Si ya conoces el framework y necesitas información específica, consulta la [documentación de la API de Actix Web][actix-web-docs].
